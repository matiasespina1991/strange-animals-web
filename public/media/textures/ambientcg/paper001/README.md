Original 2K JPG OpenGL normal and roughness maps. No color map is used: the
editor artwork remains the source of printed colors. Preview tiles the maps
six times across the sleeve, applies restrained normal strength and remaps roughness
to preserve the existing satin finish. Prepared maps are embedded in GLB exports.
